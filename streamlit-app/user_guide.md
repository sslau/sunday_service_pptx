# 崇拜投影片編輯器 · 使用手冊

一個用瀏覽器即可完成「編輯內容 → 製成崇拜投影片」的網頁工具。
內容存在 Google 試算表，產生的 `.pptx` 直接在瀏覽器下載，不需在本機安裝
PowerPoint 或架設伺服器。

---

## 1. 開始使用

1. 開啟 App 網址並登入（由 Streamlit Community Cloud 的帳號權限控制）。
2. 首次進入會停在左側「主日日期」清單中最新的日期；若還沒有資料，會以
   預設週次建立。
3. 左側面板由上到下依序是：

| 控制項 | 用途 |
| --- | --- |
| 主日日期 | 切換不同主日；切換後編輯頁內容會跟著換。 |
| 儲存目前內容 | 把目前這一頁所有輸入存回資料來源（試算表／本機）。 |
| 製成整場投影片（合併＋編譯） | 依目前設定產生整份 `Sunday_Service_<日期>.pptx`。 |
| 新增週次 | 輸入 `YYYY.MM.DD` 後按「新增並開啟」，可建立新的一週。 |

> 產製成功後，下載按鈕會出現在「製成整場投影片」按鈕的正下方。

---

## 2. 編輯內容（分頁一）

頁面上方是兩個並排的經文區塊，下方是詩歌，最後是講道、公佈事項與聖餐。

### 1. 宣召經文
- **出處**：例如 `詩篇 34:1-3`。也可先用右側 **書卷** 下拉選單選書名，
  會自動填入出處。
- **從 fhl.net 聖經網輸入**：輸入出處後按此鈕，會自動由信望愛聖經網
  （bible.fhl.net）抓取經文填入下方內容：**整段連續文字、每一節前有
  `[書編 章:節]`、無空版（神）**，等同網站 `&TABFLAG=2`（整段）＋ `SSS=2`
  （無空版）的顯示；仍可再手動修改或直接貼上。書卷可用全名或簡稱（詩篇／詩、
  羅馬書／羅、約翰一書／約一…）；範圍支援 `12:1-8`、`1:1-2:3`（跨章）。
  **可一次抓取多卷書**：出處以 `；`、`;` 或換行分隔多個經文，
  例如 `詩篇 100:1-2；約翰福音 3:16`。每卷書會各自成為一段，段首是該卷的
  「書 章:節」標題（例如 `詩篇 100:1-2`），再依序排入投影片。
  出處後可加譯本，例如 `（和合本）`、`（新譯本）`、`（現代中文譯本2019版）`，
  未指定時預設和合本。
- **出處字型 / 內文字型**：單位 pt。內文字型最小 44pt。
- **內容**：把整段經文貼進同一個框即可，系統會**自動分頁**（見第 4 節）。

### 3. 經文（讀經）
- 與宣召經文相同，差別是句數通常較多。
- 一樣只貼「一段連續文字」，不用自己分頁或分節。

### 2. 詩歌敬拜
- 頁面上可設定全域的**歌詞字體 / 最小字體 / 左右邊距**。
- 每首詩歌以卡片呈現，可填：曲名、英文名、來源、副歌、每段歌詞。
- 「每段後重覆副歌」勾選時，副歌會自動插在每段之後。
- 按「＋ 新增一段」增加段落、「移除這首詩歌」刪除整首。
- 背景圖依序取自 `media/song_bg1.jpg` 等，可在製成頁替換。

### 4. 講道信息（Sermon）
- 此節**只接受現成的 `.pptx`**：請到「製成投影片」頁上載，編輯頁不需輸入。

### 5. 公佈事項（Announcements）
- 同上，**只接受現成的 `.pptx`**，於「製成投影片」頁上載。

### 6. 聖餐（Communion）
- 勾選後會在信息之後加入「聖餐＋使徒信經」兩頁。
- **當月第一主日**會自動預設勾選。

## 3. 製成投影片（分頁二）

1. **上載要合併的檔案（可選）**：三格分別對應詩歌敬拜、講道信息、
   公佈事項。上了檔案的那一節，製成時就**以檔案為準**（格式沿用來源檔）；
   留空則用編輯頁的內容現場編譯。可混用。
2. **輸入檔名（本機執行時）**：展開「或輸入檔名」，系統會從 App 資料夾、
   `data/downloads`、`~/Downloads` 找檔合併；找不到會自動回退並提示。
3. **替換背景圖片（可選）**：可逐一替換各節的標題背景圖。
4. **公佈事項圖片（可選）**：若公佈事項是「圖片型」，可在此附加圖片。
5. **自動使用先前儲存／已產生的各節投影片**：預設開啟。開啟時，同一日期
   先產生過的節會自動沿用；取消則全部用編輯頁內容重新編譯。
6. **各節來源狀態**：製成前可確認每一節的來源：
   - 已上載／檔案（以檔案為準）
   - 已儲存（沿用先前產生的檔案）
   - 現場編譯（用編輯頁內容）
7. 回左側按「製成整場投影片」，完成後按「⬇ 下載 PPTX」取得
   `Sunday_Service_<日期>.pptx`。

> 「個別產生獨立 pptx」區塊可單獨產生詩歌／講道／公佈事項三節，方便先傳給
> 其他同工；產生的檔案也會自動儲存，供整場合併沿用。

## 4. 經文自動分頁規則

- 貼上的經文會被視為一段連續文字，系統依**字型大小推算每行可容納的字數**，
  再依文字框高度決定每頁行數，自動切成多頁。
- **字型固定由 44pt 起算**：預設 44pt，可調高但不可低於 44pt。
- 分頁會避開標點：每一頁（行）**結尾不會是標點符號**，下一頁也不會以標點
  開頭。
- 中文沒有詞與詞之間的空格，因此換頁點會落在句子中間。若需要「在句末
  標點後換頁」的相反規則，請提出調整。

---

## 5. 儲存與資料

- **週次內容**：寫入 Google 試算表（`weeks` 分頁）。App 部署在 Streamlit
  Community Cloud 時，伺服器磁碟是暫時性的，所以內容不放在伺服器檔案。
- 未配置試算表時，本機執行會自動改用 `data/weeks.json` 作為備份。
- 上載的圖片與「個別產生」的節檔案存在伺服器 `data/decks/`；在雲端會隨
  重啟清除，本機則保留。

## 6. 常見問題

**Q：合併後 PowerPoint 出現「需要修復」？**
A：合併功能已修正母片／版面 ID 衝突問題，正常情況不會再出現。若仍發生，
請確認來源 `.pptx` 本身可在 PowerPoint 正常開啟。

**Q：上載檔案後，編輯頁還需要填嗎？**
A：不需要。該節只要上載了檔案，製成時就以檔案為準。

**Q：為什麼改了編輯頁內容，製成結果沒變？**
A：可能該節有上載檔案，或勾選了「自動使用先前儲存」而沿用了舊檔。可取消
該開關或重新上載，再製成。

**Q：下載按鈕不見了？**
A：請按左側「製成整場投影片」重新產生一次；下載按鈕只會顯示目前日期最近
一次產生的結果。
